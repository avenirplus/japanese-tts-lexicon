# japanese-tts-lexicon

日本語TTS（読み上げ）の誤読を、教材・動画・Webアプリをまたいで蓄積・再利用するための共通読み辞書です。

## 設計原則

1. 一度見つけた誤読は、共通辞書に登録して再発させない。
2. `山→やま` のような単漢字の一括置換はしない。`富士山→ふじさん` のように語単位で扱う。
3. 長い語を先に照合する。
4. 表示用テキストと読み上げ用テキストを分離する。
5. 同一表記に複数読みがある場合は `context` を持たせ、自動一括置換しない。
6. 不確かな読みは推測で固定せず、確認してから正本へ追加する。
7. 教材完成時には、その教材が使う読みを `ttsQ` / `ttsA` / `ttsText` 等として固定保存し、実行時の外部辞書依存を避ける。

## 初期資産

- 中学受験社会・地理を中心に **462語**
- 共通語: `血税→けつぜい`、`出生率→しゅっしょうりつ` など
- 回帰テスト: 富士山、血税、英虞湾、八幡製鉄所、神通川、根釧台地、嬬恋村など

## ディレクトリ

- `data/core/` 一般語
- `data/social/` 地理・歴史・公民
- `data/science/` 理科
- `data/proper-nouns/` 人名・地名・学校名
- `data/custom/` 個別上書き
- `data/contextual-readings.json` 文脈で読みが変わる語
- `dist/lexicon.json` 全辞書を統合した配布用JSON
- `tests/` 誤読再発防止テスト
- `schema/` 辞書データ形式

## コマンド

```bash
npm run build
npm test
npm run audit -- 原稿.txt
```

`audit` は原稿から、辞書で処理できなかった漢字候補を抽出します。読みを勝手に推測せず、確認対象として出すためのものです。

## 教材側での推奨利用

教材生成時に本文から語彙を抽出し、この辞書と照合します。
未登録語は「読み未確認」として洗い出し、確認後にこのリポジトリへ戻します。
完成教材には読み上げ専用文字列を内包します。

```js
{
  q: "日本で最も高い山は何ですか。",
  a: "富士山",
  ttsQ: "にほんで もっとも たかい やまは なんですか。",
  ttsA: "ふじさん"
}
```

これにより、端末やTTSエンジンが変わっても読みを機械任せにしません。
