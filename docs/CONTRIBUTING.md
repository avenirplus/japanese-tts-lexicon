# 読み辞書の追加ルール

1. 実際に誤読した語、または教材で重要な語を追加する。
2. 地理など大量語彙は `表記<TAB>よみ` のTSVで管理する。
3. 一般語は `data/core/general.json` に追加する。
4. 一度見つけた誤読は必ず `tests/regression.json` にも追加する。
5. 同一表記で複数読みがある語は通常辞書へ入れず、`data/contextual-readings.json` に登録する。
6. `山→やま` のような単漢字の一括変換は禁止する。
7. 正しい読みを確認できていないものは正本へ確定登録しない。
8. 表示用テキストと読み上げ用テキストは分離する。

## 原則

**一度発見した誤読は、二度と別教材で起こさない。**
